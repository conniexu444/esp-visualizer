Supported sketch features
Open a single Arduino .ino or C++ file. The preview supports common TFT_eSPI shapes, RGB565 colors, rotation, classic bitmap text, Serial output, millis(), delay(), and CST816S touch position via Wire (registers 0x02–0x06). Declare helper functions before you call them.
Use the physical board to verify electrical behavior, sensor readings, radio, and timing. LVGL, MicroPython, custom drivers and additional libraries need their own runtime. The included sketch uses the board-specific TFT_eSPI configuration when built for hardware.
